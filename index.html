Analisis Komparasi Aturan Warna RGB-YCbCr dan RGB-HSV sebagai Pra-pemrosesan Deep Learning pada Deteksi Kebakaran Drone

Latar Belakang

Akar Masalah

  • Tantangan Visual Pemantauan Udara: Objek api pada citra drone seringkali berukuran sangat kecil dan berbaur dengan dinamika pencahayaan luar ruangan (outdoor).
  • Kelemahan Deep Learning Murni: Model yang murni mengandalkan data (data-driven) rentan menghasilkan alarm palsu (false positive) akibat objek pengecoh (noise visual) seperti pantulan cahaya atap atau dedaunan kering.
  • Krisis Sumber Daya Komputasi: Arsitektur deep learning memberikan beban komputasi yang berat pada perangkat drone (UAV), mengorbankan kecepatan pemrosesan dan menghilangkan kemampuan deteksi real-time.
Latar Belakang

Solusi & Research Gap

  • Solusi Pra-pemrosesan Warna: Segmentasi ruang warna (RGB, YCbCr, HSV) terbukti sangat ringan secara komputasi dan efektif dalam menyaring kandidat area api dari noise visual sebelum masuk ke model Deep Learning.
  • Research Gap: belum ada komparasi langsung yang menguji efektivitas kombinasi aturan warna ( RGB-YCbCr vs RGB-HSV) sebagai lapis pra-pemrosesan deep learning pada perangkat drone.
  • Fokus Optimalisasi: Menemukan "titik seimbang" (trade-off) paling ideal antara tingkat akurasi (menekan false positive) dan kecepatan komputasi real-time di perangkat bersumber daya terbatas.
Pertanyaan Penelitian

Rumusan Masalah

  1. Bagaimana perbandingan tingkat akurasi (khususnya menekan false positive) antara penggunaan kombinasi aturan warna RGB-YCbCr dan RGB-HSV sebagai metode pra-pemrosesan model deep learning untuk deteksi kebakaran?
  2. Bagaimana pengaruh penerapan kedua metode tersebut terhadap beban komputasi dan efisiensi waktu pemrosesan (Frame Per Second / FPS) saat diimplementasikan secara real-time melalui citra drone?
Ruang Lingkup

Batasan Masalah

  • Fokus Filter: Terbatas pada perbandingan dua kombinasi metode pra-pemrosesan warna: RGB-YCbCr dan RGB-HSV.
  • Model Klasifikasi: Menggunakan satu arsitektur deep learning yang telah ditetapkan sebagai variabel tetap (SSD atau YOLO)
  • Kondisi Pengujian: Pengenalan piksel api difokuskan pada lingkungan luar ruangan (outdoor) menggunakan dataset citra atau video udara dari UAV/drone.
  • Metrik Evaluasi: Difokuskan pada akurasi sistem (khususnya tingkat penolakan false positive) dan efisiensi waktu komputasi (Frame Per Second / FPS).
  • Batasan Teknis: Ranah penelitian berfokus murni pada rekayasa perangkat lunak (computer vision), tidak mencakup perancangan hardware fisik, maupun sistem kendali terbang drone.
Sasaran & Kontribusi

Tujuan & Manfaat Penelitian

🎯 Tujuan Penelitian

  • Membandingkan tingkat akurasi (khususnya efektivitas menekan false positive) antara kombinasi RGB-YCbCr dan RGB-HSV
  • Mengukur dan menganalisis beban komputasi serta kecepatan pemrosesan secara real-time pada drone.

💡 Manfaat Penelitian

  • Teoretis: Menjawab research gap terkait efisiensi komputasi filter ruang warna pada arsitektur deep learning berdaya terbatas.
  • Praktis: Memberikan rekomendasi arsitektur optimal bagi developer computer vision dan menjadi landasan sistem mitigasi bencana udara yang andal bagi instansi terkait (BNPB/Pemadam Kebakaran).
